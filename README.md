# Real Estate Lead Matching API

This project is a simple backend service built with FastAPI that simulates a real estate listing and buyer matching system.

The API allows users to:

- Create property listings
- Register buyer preferences
- Match buyers to listings using scoring logic
- View basic analytics (total listings, buyers, average price)


---

## Tech Stack

- FastAPI
- Python
- SQLAlchemy
- Pydantic
- SQLite
- Docker (optional)

---

## Key Concepts Implemented

- REST API development
- Data validation with Pydantic
- Relational database modeling
- Basic scoring algorithm (matching logic)
- Modular project structure
- CRUD operations
- Aggregation queries
