# Real Estate Lead Matching System

This project is a full-stack real estate matching system built using FastAPI (backend) and React (frontend).

It simulates how buyers are matched with property listings based on preferences such as price, location, and bedroom requirements.

---

## What This Project Does

The system allows users to:

- Create property listings
- Register buyer preferences
- Match buyers to listings using scoring logic
- View basic platform analytics (total listings, buyers, average price)
- Interact through a simple React dashboard

---

## Architecture

### Backend (FastAPI)
- RESTful API endpoints
- SQLAlchemy ORM with relational schema
- Pydantic request validation
- Matching algorithm service layer
- Aggregation queries for analytics
- Docker-ready structure

### Frontend (React)
- Simple dashboard for interacting with backend
- Axios API integration
- Form handling and state management
- Match results display
- Analytics visualization
